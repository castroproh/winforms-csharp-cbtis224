# Papelería Escolar

Windows Forms, **.NET Framework 4.8**. Ábrelo con Visual Studio en Windows (`Papeleria.sln`).

| Formulario | Qué hace |
|---|---|
| Form1 | Bienvenida: nombre del alumno y MenuStrip (opciones, color Azul / Verde / Original, salir) |
| Form2 | Hacer pedido: ComboBox, RadioButton (suelto, paquete de 3, caja), CheckBox |
| Form3 | Catálogo de productos: ComboBox, GroupBox, ListBox |
| Form4 | Zona de descanso: reproduce `Motivator.mp3` con Windows Media Player (creado por código con `WMPlayer.OCX`) y revisa si una palabra es palíndromo |
