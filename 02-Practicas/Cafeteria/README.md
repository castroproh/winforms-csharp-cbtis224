# Cafetería Escolar

Windows Forms, **.NET Framework 4.8**. Ábrelo con Visual Studio en Windows (`Cafeteria.sln` o `Cafeteria.slnx`).

| Formulario | Qué hace |
|---|---|
| Form1 | Inicio con MenuStrip |
| Form2 | Hacer pedido: ComboBox, RadioButton dentro de GroupBox, CheckBox, ListBox |
| Form3 | Menú de la semana: ComboBox, GroupBox con el día, ListBox |
| Form4 | Música con Windows Media Player (archivo `Caifanes audio.mp3`) |

Requiere el control ActiveX de Windows Media Player (viene con Windows).
