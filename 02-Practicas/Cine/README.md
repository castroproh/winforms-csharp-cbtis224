# Cine Estrella

Windows Forms, **.NET Framework 4.8**. Ábrelo con Visual Studio en Windows (`Cine.sln` o `Cine.slnx`).

| Formulario | Qué hace |
|---|---|
| Form1 | Inicio con MenuStrip |
| Form2 | Comprar boletos: ComboBox, RadioButton dentro de GroupBox, CheckBox, NumericUpDown |
| Form3 | Cartelera de la semana: ComboBox, GroupBox con el día, ListBox |
| Form4 | Sala de espera con música (Windows Media Player, archivo `Musica.mp3`) |

Requiere el control ActiveX de Windows Media Player (viene con Windows).
