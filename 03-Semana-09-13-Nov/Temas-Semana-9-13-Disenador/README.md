# Temas semana 9 - 13 de noviembre (Windows Forms C#, .NET 8)

Abre `Temas-Semana-9-13.sln` con Visual Studio 2022 y presiona F5.

| Menú | Tema | Qué muestra |
|---|---|---|
| 5a | Panel | PANEL-DATOS: dos paneles, Ocultar / Mostrar / Limpiar / Salir |
| 5 | TabControl y Panel | Cuatro fichas: PANEL (con scroll), BOTONES, LABEL, TEXTBOX |
| 6 | Control Panel | CheckBox dentro de un Panel y recorrido con foreach |
| 7 | TableLayoutPanel | Tabla 2x2 con 4 botones y tabla 1x2 (Saludar / Despedir) |
| 8 | RoundButton | Clase RoundButton que hereda de Button (OnPaint, GraphicsPath, Region) |
| 10 | GroupBox | RadioButton dentro y fuera del GroupBox |
| 13 | MouseEnter en Panel | MouseEnter / MouseLeave cambian el color del panel |
| 18 | Usuario y contraseña | Alumno1 / Cbtis224, contraseña oculta, 3 intentos |
| 19 | Usuario y contraseña | Aloha1 / 1234, Administrador / admin, Empleado / 0000 |

Los controles se crean por código en cada formulario y las imágenes se dibujan en código.
