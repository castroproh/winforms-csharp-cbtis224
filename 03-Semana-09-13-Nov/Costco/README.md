# Costco — Temas semana 9–13 de noviembre

Windows Forms, **.NET 8**. Abre `Temas semana 9 - 13.sln` con Visual Studio y presiona F5.

| Menú | Formulario | Tema |
|---|---|---|
| Paneles | Form2 | Panel: ofertas de la semana |
| TabControl | Form3 | TabControl con paneles |
| TableLayoutPanel | Form4 | TableLayoutPanel |
| RoundButton | Form5 | Clase `RoundButton` (botón redondeado) |
| GroupBox | Form6 | GroupBox con RadioButton |
| Usuario-Contraseña | Form7 | Login con contraseña oculta y límite de intentos (`socio` / `costco123`, 3 intentos) |

No incluye MouseEnter en Panel ni "Control Panel"; esos dos temas están en `../Temas-Semana-9-13`.
