# SEC2-IG1

Proyecto Windows Forms (C#, .NET 8) con las herramientas de la Secuencia 1 y de la semana del 2 al 6 de noviembre de 2026.

## Cómo abrirlo
1. Descomprime el ZIP.
2. Abre `SEC2-IG1.sln` con Visual Studio 2022 (carga de trabajo "Desarrollo de escritorio con .NET").
3. Presiona F5.

## Formularios
| Formulario | Herramientas |
|---|---|
| FormInicio | Timer de 3 s, Label |
| Form1 (menú) | MenuStrip, Button, ToolTip, DateTime.Now |
| FormPaneles | Panel, PictureBox, TextBox, Button, Visible |
| FormRectangulo | TextBox, PictureBox, try/catch, MessageBox, DateTime.Now, Focus (lados de 1 a 50) |
| FormCalculadora | Convert.ToDouble, MouseHover, MouseLeave |
| FormFechas | DateTimePicker, ToolTip, LinkLabel |
| FormControles | ComboBox, GroupBox, RadioButton, CheckBox, NumericUpDown, ListBox |
| FormHerramientas | ListView con grupos, Timer |

Los controles se crean por código en el constructor de cada formulario (no hay archivos .Designer).
